# Risks to Watch for When Working with AI

The HTML slide deck for the second AI Recharge Station talk (in Traditional Chinese).

**Live slides: <https://allenphant.github.io/ai-collab-risks-talk/>**

- Controls: arrow keys to navigate; the icon at the bottom left opens the overview; `L` toggles the laser pointer.
- Cards can be clicked to expand details and sources.
- Content: three categories of risk (users, AI, attackers) and one set of safeguards configured in advance. Every case cites its sources.
- This repo contains only the built deck, `index.html` (a single self-contained file).
